## NON-NEGOTIABLE DESIGN RULES (UDEC 8.5 FLOOR)

### Typography
- Display: **Cormorant Garamond** (or system equivalent)
- Body: **DM Sans**
- Data/code: **JetBrains Mono**
- No other typefaces permitted

### Color
- Background: `#0d0f0e` (near-black)
- Text: `#f0ede6` (warm off-white)
- Accent: **single color maximum** — never purple
- No gradient abuse, no glassmorphism

### Layout
- Steve Krug principles: "Don't Make Me Think"
- One obvious action per screen
- Scannable section headings
- No cognitive load at the top
- Billboard speed comprehension (3 seconds)

### Visual
- Luxury minimalism aesthetic (Stripe, Linear, GitHub)
- No pills overload, no oversized radii
- No generic AI-generated UI patterns
- High-end editorial quality only
- Awwwards SOTD caliber required
