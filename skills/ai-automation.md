# AI Automation Skills

## Ralphy
- Repository: https://github.com/michaelshimeles/ralphy.git
- Use when automating multi-step development tasks, building batch workflows, or orchestrating agents.
- Ideal for building a repeatable directory development pipeline and supervising the new backend dashboard build.

## jcodemunch-MCP
- Repository: https://github.com/jgravelle/jcodemunch-mcp.git
- Default token compression engine for this project.
- Use for compressing source code, indexing the repository, and shrinking prompt context during agent planning.
- Local clone path: `external-tools/jcodemunch-mcp`

## Pauli-Uncodixfy
- Repository: https://github.com/executiveusa/pauli-Uncodixfy.git
- Use to enforce clean UI/UX patterns and maintain high-quality design with token-efficient component generation.

## Pauli-Taste-Skill

## Pauli-Blog
- Repository: git@github.com:executiveusa/pauli-blog.git
