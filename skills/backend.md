# Backend Skills

## Supabase MCP
- Repository: https://github.com/supabase-community/supabase-mcp.git
- Use for backend API generation, database integration, and multi-tenant services.

## MCP2CLI
- Repository: https://github.com/knowsuchagency/mcp2cli.git
- Use for building CLI wrappers and integration pipelines for MCP-based backends.

## AST Grep MCP
- Repository: https://github.com/ast-grep/ast-grep-mcp.git
- Use for code analysis, source-to-source refactoring, and smart code extraction.

## Paperclip
- Repository: https://github.com/paperclipai/paperclip.git
- Use for backend scaffolding, asset pipelines, and service orchestration.

## Graphify
- Repository: https://github.com/safishamsi/graphify.git
- Use for data graph generation, API documentation, and schema modeling.

## Directory and Tenant Infrastructure
- `mcp2cli` + `supabase-mcp` are the core backend integration stack for tenant and directory management.
