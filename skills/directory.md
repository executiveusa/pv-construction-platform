# Directory & Multitenant Management Skills

## Goal
Build a resilient, trust-first multitenant directory platform that can:

- onboard clients as listings
- generate custom landing pages for each client
- capture leads and route them to the right team
- surface trust signals and agency-level credibility
- support agentic search and directory navigation

## Key Repositories for this use case

- `https://github.com/supabase-community/supabase-mcp.git` — tenant-aware backend services.
- `https://github.com/knowsuchagency/mcp2cli.git` — CLI and devops integration for MCP workflows.
- `https://github.com/ast-grep/ast-grep-mcp.git` — code analysis for content generation and directory automation.
- `https://github.com/browser-use/browser-harness.git` — test the directory funnels and client onboarding flows.
- `https://github.com/vercel-labs/opensrc.git` — frontend deployment and edge optimization.

## Use cases

- Build client landing pages on demand using a template-driven system.
- Manage listings from a backend dashboard with tenant isolation.
- Generate new lead capture pages for clients based on service category and geography.
- Maintain a trust-aware content layer so agents can understand the brand, service model, and directory taxonomy.
