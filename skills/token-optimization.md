# Token Optimization Skills

## jcodemunch-MCP
- Repository: https://github.com/jgravelle/jcodemunch-mcp.git
- Primary token compression and code summarization tool for the project.
- Use with large file contexts, agent prompts, and repository indexing.

## RTK
- Repository: https://github.com/rtk-ai/rtk.git
- Use to save tokens for agent prompts and maintain efficient LLM context usage.
- Local clone path: `external-tools/rtk`

## Context & Agent Cache
- `https://github.com/upstash/context7.git`
- This repository is useful for managing agent context and preserving relevant state while limiting prompt size.

## Token-Safe Design
- `https://github.com/executiveusa/pauli-Uncodixfy.git`
- Use design rules and clean code generation to reduce token waste from verbose markup and repeated styles.
